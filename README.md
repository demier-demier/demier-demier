# Bernardo Demier

**Applied AI · Agent systems · Security engineering**

I build tools for the practical questions behind AI products: which context should an agent see, how do we evaluate its behavior, and what should happen before it acts?

My work connects software engineering, computational methods, and defensive security. These projects make the implementation, evidence, and limitations easy to inspect.

## Featured projects

| Project | What it does | Start here |
| --- | --- | --- |
| [Semantic Context Lab](https://github.com/demier-demier/semantic-context-lab) | Runs local embeddings and compares lexical, semantic, and hybrid retrieval under a context budget. | Measured retrieval results, source provenance, interactive report |
| [MCP Contract Guard](https://github.com/demier-demier/mcp-contract-guard) | Detects changes in an agent's MCP tool definitions and requires review before accepting a new contract. | Definition fingerprints, CI gate, JSON/SARIF review output |
| [Incident Evidence Workbench](https://github.com/demier-demier/incident-evidence-workbench) | Correlates security events into triage cases with timelines and traceable evidence. | Local investigation UI, detection rules, optional loopback model adapter |

## Agent engineering foundations

| Project | Engineering focus |
| --- | --- |
| [Agent Eval Kit](https://github.com/demier-demier/agent-eval-kit) | Replay multi-step traces and evaluate tool use, task outcomes, cost, and policy violations. |
| [Context Ledger](https://github.com/demier-demier/context-ledger) | Retrieve context with access boundaries, source versions, freshness, and citations. |
| [Tool Approval Gateway](https://github.com/demier-demier/tool-approval-gateway) | Bind human approvals to proposed tool actions, with expiry, replay protection, and an audit trail. |

All six are standalone reference implementations with original synthetic fixtures, documented tradeoffs, reproducible demos, and automated tests. The repositories distinguish measured model behavior from deterministic rules and test doubles.
