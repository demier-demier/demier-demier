# Bernardo Demier

**Applied AI · Agent systems · Security engineering**

I build tools for the practical questions behind AI products: which context should an agent see, how do we evaluate its behavior, and what should happen before it acts?

My work connects software engineering, computational methods, and defensive security. These projects make the implementation, evidence, and limitations easy to inspect.

**[Try the live demos →](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/)** No installation or account required. Explore public-data applications, native 3D artifacts, and interactive engineering labs.

## Applied cases with inspectable evidence

- **[CISA vulnerability research](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/policy-rag-lab/kev.html):** search 120 attributed public records with governed evidence export. An optional local Qwen CLI produces a bounded draft with measured inference and source binding.
- **[Durable analyst report](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/agent-runtime-lab/kev.html):** follow the same evidence through an approval-bound file publication, an actual worker crash, and recovery that verifies the original bytes. Model suggestions remain subject to review.
- **[Native CAD to Blender](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/):** inspect an original Raspberry Pi 5 mounting tray and download editable native files. Two reopened Fusion variants preserve 13 parameters and 43 history items; physical fit is not validated. [Source](https://github.com/demier-demier/studio-agent-bridge).
- **[Complete Blender → Unreal environment](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/environment/):** explore an original laboratory with 1,571 mesh instances, 17 materials and editable day/night scenes. Chat-directed native operations preserve revisions and reconstruct a saved Unreal level, independently reopened and rendered on the GPU. The browser shows exported results; robot control and gameplay are outside this case. [Download source](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge-source.zip).
- **[Recovery for native agent workflows](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/recovery/):** inspect real process-interruption traces, persisted intent and blocked retries in Studio Agent Bridge. The read-only MCP recovery report preserves uncertain outcomes for explicit review. These fault-injection cases use synthetic host adapters, not Blender or Unreal execution. [Reproduce the experiment](https://github.com/demier-demier/studio-agent-bridge/tree/main/examples/recovery).
- **[Source-bound Blender revisions](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/source-binding/):** a stale scene hash stops an edit before Blender launches; a valid request edits a preserved snapshot. Compare real renders of a 28-component cart revision and download editable scenes. The revised laboratory was reopened in Unreal with 1,571 mesh actors; an initial NullRHI crash and the explicit GPU retry are documented. This case verifies target structure, not Unreal appearance. [Native evidence and reproduction](https://github.com/demier-demier/studio-agent-bridge/tree/main/examples/source_binding).

The Studio follow-up now [rejects that known Unreal launch failure before imports](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/source-binding/#unreal-preflight). Two real blocked requests preserved their native project state with zero subprocesses. A separately selected GPU build and fresh inspection verified the original lab's 1,571 actors and 84 shared mesh assets. The rule is specific to the observed macOS/Unreal 5.7.4 environment-build combination; no appearance or performance claim is made for this run.

The environment's current v2 download also [checks native files before sharing](https://github.com/demier-demier/studio-agent-bridge/tree/main/examples/publication_safety): independently reopened Blender copies, narrowly rewritten FBX path metadata, a separately verified Unreal transfer, and a publication gate that scans decompressed scene data. Historical inputs remain identifiable by their original hashes. This is a bounded privacy and model-preservation check, not a general security certification.
