# Bernardo Demier

**Security engineering · Rust · Applied AI**

I build tools for security investigations and reliable AI systems: which events deserve attention, can the evidence be verified, and what should happen before an agent acts?

My work connects software engineering, computational methods, and defensive security. These projects make the implementation, evidence, and limitations easy to inspect.

**[Try the live demos →](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/)** No installation or account required. Explore public-data applications, native 3D artifacts, and interactive engineering labs.

## Applied cases with inspectable evidence

- **[Robot Cyber Shield — robot command and data security](https://github.com/demier-demier/robot-cyber-shield):** Rust verifies authority grants and per-request holder signatures, persists replay/revocation state, and minimizes telemetry before export. A real ROS 2 / SROS2 lab checks unauthorized command publishers and raw-data readers, alongside permitted synthetic robot motion. [Watch the interactive 3D demonstration](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/robot-cyber-shield/) with live Rust/WASM command checks and explicitly recorded ROS 2 camera-access evidence, or [Reproduce the native lab](https://github.com/demier-demier/robot-cyber-shield/blob/main/docs/ROS2.md). The actuator and sensor payloads are synthetic; physical stopping and production deployment remain unvalidated.
- **[Tracebound — verifiable financial investigation](https://github.com/demier-demier/tracebound):** Rust calculates exact minimum/maximum allocations through temporal transaction networks, with independently checkable optimality certificates. A Python/SQLite workspace preserves cases, source artifacts, role-separated reviews and audit history; normalized PostgreSQL and CSV ingestion are exercised against original synthetic ledgers. [Follow a payment in the live workbench](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/tracebound/) or [inspect a recorded reviewed dossier](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/tracebound/review.html). The independent oracle checked 1,710 intervals and 3,420 witnesses. No bank deployment, actual fund provenance or crime-detection accuracy is claimed.
- **[Postgres Audit Guard — Rust security tooling](https://github.com/demier-demier/postgres-audit-guard):** bounded PostgreSQL log triage, externally anchored evidence and SQL-free ECS exports. [Financial transfer investigation](https://github.com/demier-demier/postgres-audit-guard/blob/main/docs/FINANCIAL-CRIME.md) adds explainable collection/outflow and three-account return patterns, exact monetary evidence and canonical report replay. A real PostgreSQL lab round-trips 58 synthetic transfers across 12 scenarios, retaining an intentionally benign matching settlement for analyst review. [Versioned analyst cases](https://github.com/demier-demier/postgres-audit-guard/blob/main/docs/ANALYST-CASES.md) preserve explanations, referrals and reopening as source-bound snapshots; previous reviews and the original alert remain intact. Actor identities are unverified and no account action is automated. [Reproduce the tests and measurements](https://github.com/demier-demier/postgres-audit-guard/blob/main/docs/RESULTS.md). The optional [Filebeat/Elasticsearch integration](https://github.com/demier-demier/postgres-audit-guard/blob/main/docs/ELASTIC.md) validates bounded ECS batches, uses stable create-only document IDs and measures restart/replay without replacing stored alerts. Strict sink checks reject injected fields; source evidence stays separately anchored. Detection is deterministic and the real integration lab uses synthetic records; production readiness is not claimed.
- **[Native Rust robotics and granular physics](https://github.com/demier-demier/studio-agent-bridge/tree/main/rust/scenward-render):** live wgpu/Metal integration of 961,191 grains, native MuJoCo robot dynamics and a detailed Blender laboratory. [Measured GPU/host profiles](https://github.com/demier-demier/studio-agent-bridge/blob/main/rust/scenward-render/PROFILING.md) separate solver, coupling and rendering costs, with reproducible reports and independent CPU-reference checks. Full-detail physical real time remains unmet; this is classical simulation/control, not a trained policy.
- **[Evidence Review Workbench](https://github.com/demier-demier/policy-rag-lab/blob/main/docs/evidence-review.md):** exact source spans, persistent claim reviews, explicit approval decisions and revocation-aware export. Three real HTTP/SQLite workflows cover technical disclosure, support policy and robotic inspection handoff. The cases are synthetic and decisions scripted; source integrity is checked automatically, semantic truth is not. [Observed outcomes](https://github.com/demier-demier/policy-rag-lab/blob/main/docs/review-observed.json).
- **[CISA vulnerability research](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/policy-rag-lab/kev.html):** search 120 attributed public records with governed evidence export. An optional local Qwen CLI produces a bounded draft with measured inference and source binding.
- **[Durable analyst report](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/agent-runtime-lab/kev.html):** follow the same evidence through an approval-bound file publication, an actual worker crash, and recovery that verifies the original bytes. Model suggestions remain subject to review.
- **[Native CAD to Blender](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/):** inspect an original Raspberry Pi 5 mounting tray and download editable native files. Two reopened Fusion variants preserve 13 parameters and 43 history items; physical fit is not validated. [Source](https://github.com/demier-demier/studio-agent-bridge).
- **[Complete Blender → Unreal environment](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/environment/):** explore an original laboratory with 1,571 mesh instances, 17 materials and editable day/night scenes. Chat-directed native operations preserve revisions and reconstruct a saved Unreal level, independently reopened and rendered on the GPU. The browser shows exported results; robot control and gameplay are outside this case. [Download source](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge-source.zip).
- **[Recovery for native agent workflows](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/recovery/):** inspect real process-interruption traces, persisted intent and blocked retries in Studio Agent Bridge. The read-only MCP recovery report preserves uncertain outcomes for explicit review. These fault-injection cases use synthetic host adapters, not Blender or Unreal execution. [Reproduce the experiment](https://github.com/demier-demier/studio-agent-bridge/tree/main/examples/recovery).
- **[Source-bound Blender revisions](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/source-binding/):** a stale scene hash stops an edit before Blender launches; a valid request edits a preserved snapshot. Compare real renders of a 28-component cart revision and download editable scenes. The revised laboratory was reopened in Unreal with 1,571 mesh actors; an initial NullRHI crash and the explicit GPU retry are documented. This case verifies target structure, not Unreal appearance. [Native evidence and reproduction](https://github.com/demier-demier/studio-agent-bridge/tree/main/examples/source_binding).

The Studio follow-up now [rejects that known Unreal launch failure before imports](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/source-binding/#unreal-preflight). Two real blocked requests preserved their native project state with zero subprocesses. A separately selected GPU build and fresh inspection verified the original lab's 1,571 actors and 84 shared mesh assets. The rule is specific to the observed macOS/Unreal 5.7.4 environment-build combination; no appearance or performance claim is made for this run.

The environment's current v2 download also [checks native files before sharing](https://github.com/demier-demier/studio-agent-bridge/tree/main/examples/publication_safety): independently reopened Blender copies, narrowly rewritten FBX path metadata, a separately verified Unreal transfer, and a publication gate that scans decompressed scene data. Historical inputs remain identifiable by their original hashes. This is a bounded privacy and model-preservation check, not a general security certification.

The [inspection workcell revision](https://bernardo-demier-ai-lab.fancy-fly-9200.chatgpt.site/studio-agent-bridge/inspection-workcell/) now includes six editable utility routes, a measured disconnected-cable rejection, and fresh Blender/Unreal image evidence. The sanitized handoff preserves the measured prior mesh fields and imports 1,988 mesh instances into a separate Unreal project. Explore the 3D mesh or download the editable scene. [Reproduction and evidence](https://github.com/demier-demier/studio-agent-bridge/tree/main/examples/inspection_workcell) distinguish geometry checks from electrical function, motion safety and renderer equivalence; human visual acceptance remains pending.
