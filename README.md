# Bernardo Demier

Applied AI, software development, and computational engineering.

I am interested in the parts of agent products that make them useful in practice: finding the right context, measuring behavior across multiple steps, and controlling actions that affect other people or systems.

## Engineering projects

| Project | The problem it explores | What to inspect |
| --- | --- | --- |
| [Agent Eval Kit](https://github.com/demier-demier/agent-eval-kit) | A plausible final answer can hide a broken or unsafe execution trace. | Trace grading, baseline/candidate comparisons, regression cases, and an interactive report. |
| [Context Ledger](https://github.com/demier-demier/context-ledger) | Useful retrieval must respect access, document versions, and expiration. | Permission-aware retrieval, citations, version invalidation, and isolation tests. |
| [Tool Approval Gateway](https://github.com/demier-demier/tool-approval-gateway) | An approval should authorize one exact action, not anything an agent does next. | Action-bound approvals, replay protection, policy decisions, and the audit trail. |

These are standalone reference implementations with synthetic data, reproducible offline demos, and tests. They are intentionally small enough to read and run. Their documentation separates implemented behavior from integration work still required in a production system.

Python, TypeScript, JavaScript, Rust, SQL, React, Next.js, and Node.js. My interests also include agent orchestration, evaluation, computational modeling, and turning operational requirements into software.
